# MainThreadBridge

**MainThreadBridge** - это лёгкая утилита для Unity, позволяющая безопасно и удобно планировать выполнение действий в *главном потоке* с задержкой, отменой и контролем состояния.

Фича особенно полезна, когда:
- нужно отложить выполнение кода без корутин;
- требуется отмена задачи до её выполнения;
- важно безопасно ловить исключения из пользовательского кода;
- нужно дождаться выполнения задачи через `Task` / `UniTask`.

---

## Основная идея

Вы создаёте *задачу* (Job), настраиваете её через `Builder`, а затем запускаете.
Внутри система:
- кладёт задачу в очередь;
- выполняет её в `Update` главного потока;
- отслеживает состояние через `Handle`.

Никаких `MonoBehaviour`, корутин или `Invoke`.

---

## Быстрый пример

```csharp
MainThreadBridge
    .CreateJob(() =>
    {
        Debug.Log("Hello from main thread!");
    })
    .WithDelay(1f)
    .Run();
```

---

## Builder API

### `CreateJob(Action action)`
Создаёт билдера задачи.

```csharp
var builder = MainThreadBridge.CreateJob(() => { });
```

### `WithDelay(float seconds)`
Задержка перед выполнением.

```csharp
.WithDelay(2.5f)
```

### `WithProtection()`
Защищает выполнение от исключений.
Если внутри будет `Exception`, она будет залогирована, но не сломает Update.

```csharp
.WithProtection()
```

### `Preserve()`
Сохраняет билдера после `Run()`, позволяя повторно запускать задачу.

```csharp
var builder = MainThreadBridge
    .CreateJob(Action)
    .Preserve();

builder.Run();
builder.Run(); // повторный запуск
```

### `Break()`
Отменяет билдера **до** запуска задачи.

```csharp
builder.Break();
```

### `Run()`
Запускает задачу и возвращает `Handle`.

```csharp
MainThreadBridge.Handle handle = builder.Run();
```

---

## Handle API

`Handle` - это идентификатор и контроллер запущенной задачи.

### `TryCancel()`
Пытается отменить задачу.

```csharp
bool canceled = handle.TryCancel();
```

### `Cancel()`
Принудительная отмена без результата.

### `IsValid()`
Задача существует и ещё не выполнена.

### `IsDone()`
Задача завершена или отменена.

---

## Ожидание выполнения

### Через `Task`

```csharp
await handle.AsTask();
```

### Через `UniTask`

```csharp
await handle.AsUniTask();
```

Можно задать интервал проверки и таймаут:

```csharp
await handle.AsTask(checkInterval: 0.1f, timeout: 5f);
```

---

## Жизненный цикл

- Все задачи выполняются **строго в главном потоке**
- Используется `PlayerLoop.Update`
- В Editor при выходе из PlayMode всё состояние автоматически очищается

---

## Потокобезопасность

- Очереди и словари защищены `lock`
- Можно создавать задачи из любых потоков
- Выполнение всегда происходит в main thread

---

## Когда использовать

✅ Отложенное выполнение без корутин  
✅ Управляемая отмена  
✅ Интеграция с async/await  
❌ Не для тяжёлых вычислений  
❌ Не заменяет Job System
